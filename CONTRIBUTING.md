# Katkı Rehberi

Bu projeye katkı vermek istediğiniz için teşekkürler.

## Geliştirme Akışı
1. Depoyu forklayın ve yeni bir branch açın.
2. Değişikliklerinizi küçük ve odaklı tutun.
3. Commit mesajlarını açıklayıcı yazın.
4. Pull Request açmadan önce derlemenin geçtiğini doğrulayın.

## Kodlama Kuralları
- Değişken, sınıf ve fonksiyon isimlerini İngilizce ve anlamlı seçin.
- Yorum satırları ve dokümantasyon metinleri Türkçe olmalıdır.
- Mevcut mimariyi bozacak büyük kapsamlı değişikliklerden kaçının.

## Pull Request Kontrol Listesi
- [ ] Değişiklik yalnızca ilgili problemi çözüyor.
- [ ] Derleme/çalıştırma adımları doğrulandı.
- [ ] Güvenlik açısından hardcoded gizli bilgi eklenmedi.
- [ ] Gerekliyse README ve ilgili dokümantasyon güncellendi.

## Davranış Kuralları
- Yapıcı, saygılı ve teknik iletişim kurun.
- Geri bildirimleri somut örneklerle verin.
